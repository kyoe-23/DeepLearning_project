# SkinAI 프로젝트 보고서

## 1. 모듈 설명

### 1.1 인증 서브시스템

#### 회원가입 모듈
- **엔드포인트**: `POST /api/auth/signup`
- **파라미터**: `{email, username, password, name}`
- **처리**: 중복 검증 → 비밀번호 암호화(bcrypt) → 사용자 생성 → JWT 발급

#### 로그인 모듈
- **엔드포인트**: `POST /api/auth/login`
- **파라미터**: `{email, password}`
- **처리**: 인증 정보 검증 → JWT 토큰 발급

#### 프로필 관리 모듈
- **엔드포인트**: `GET/PUT /api/auth/profile`
- **처리**: JWT 인증 → 프로필 조회/수정 → 비밀번호 변경

---

### 1.2 게시판 서브시스템

#### 게시글 CRUD 모듈
- **엔드포인트**: `GET/POST/PUT/DELETE /api/board/free/posts`
- **처리**: 게시글 생성/조회/수정/삭제, 조회수 증가, 검색 기능

#### 댓글/좋아요 모듈
- **엔드포인트**: `POST/DELETE /api/board/free/posts/:id/comments`
- **처리**: 댓글 작성/삭제, 좋아요 관리 (1회 제한)

---

### 1.3 AI 분석 서브시스템

#### 이미지 업로드 모듈
- **엔드포인트**: `POST /api/ai/image-upload`
- **처리**: 파일 검증(JPG/PNG, 5MB) → 서버 저장

#### AI 피부 분석 모듈
- **엔드포인트**: `POST /api/ai/survey`
- **처리**: Flask AI 호출 → ResNet50 추론 → Top-5 예측 → 설문 통합

#### 분석 결과 조회 모듈
- **엔드포인트**: `GET /api/ai/analysis/:id`
- **처리**: 분석 이력 조회 (본인만), 차트 데이터 생성

---

### 1.4 공통 모듈

#### JWT 인증 미들웨어
- **모듈**: `authenticateToken(req, res, next)`
- **처리**: 토큰 추출 → 검증 → 사용자 정보 주입

#### Rate Limiting 모듈
- **처리**: API 요청 제한 (일반 100회/분, 인증 5회/15분)

## 2. 사용자 인터페이스 절차

### 2.1 회원가입/로그인
1. 회원가입 양식 입력 (이메일, 사용자명, 비밀번호, 이름)
2. 서버 검증 및 JWT 발급
3. 자동 로그인 → 메인 페이지 이동

### 2.2 AI 피부 분석
1. **이미지 업로드**: 피부 이미지 선택 (JPG/PNG, 5MB 이하)
2. **설문 작성**: 피부 타입, 증상, 지속 기간 등 입력
3. **AI 분석**: Flask 서비스 → PyTorch 모델 추론
4. **결과 확인**: Top-5 질환 예측, 신뢰도 차트, AI 추천사항

### 2.3 커뮤니티 이용
1. 게시글 작성 (제목, 내용)
2. 게시글 조회 (조회수 자동 증가)
3. 좋아요/댓글 작성
4. 본인 글 수정/삭제

### 2.4 프로필 관리
1. 사용자 정보 조회 (이메일, 이름, 가입일, 활동 통계)
2. 프로필 수정 (이름, 비밀번호 변경)
3. 내 게시글/댓글/AI 분석 기록 확인

## 4. 시험내용 및 결과

### 4.1 시험 환경

**하드웨어**
- CPU: Apple M1/M2 또는 Intel Core i5+
- RAM: 8GB 이상
- GPU: MPS/CUDA (선택)

**소프트웨어**
- Node.js v16+, Python 3.8-3.9
- Express 4.18, Flask 2.3, PyTorch 2.0+
- 브라우저: Chrome 90+, Firefox 88+

### 4.2 시험 방법

- ✅ JWT 기반 안전한 인증 시스템 구축
- ✅ GPU 활용 시 1초 이내 AI 추론 응답

**기능적 성과**
- ✅ 회원 관리 (회원가입, 로그인, 프로필 수정)

**현재 제한사항**
